# Ascend — прокачай себя в реальной жизни

Android-приложение, в котором ты — герой RPG. Персонаж растёт, когда растёшь ты:
каждое дело из жизни становится квестом, каждый шаг приносит опыт, золото и
прокачку характеристик.

## Принципы

- **Любой прогресс засчитывается.** Хотел прочитать 20 страниц, а прочитал одну?
  Полная базовая награда твоя. Цель лишь даёт бонус (+50 %, а вдвое больше цели ещё +25 %).
- **Все пути равноценны.** Опыт зависит только от сложности квеста, а не от характеристики.
  Отжимания и чтение приносят одинаковую награду, и никто не обязывает делать что-то конкретное.
- **Без наказаний.** Пропуск ничего не отнимает: серия просто начнётся заново.
  За возвращение после перерыва даётся бонус «Возвращение героя».

## Возможности

| Раздел | Что внутри |
|---|---|
| **День** | Приветствие, карточка героя, лента недели (прошлое — летопись, будущее — план), цитата дня, «главная цель дня», кольцо прогресса, квесты на сегодня; невыполненные задачи мягко переезжают на сегодня |
| **Квесты** | Привычки (по дням недели), разовые задачи (сегодня/завтра/дата), архив. Готовые шаблоны, цели с количеством, время, сложность, связь с книгой |
| **Книги** | Библиотека со сгенерированными обложками, прогресс по страницам, ежедневный квест чтения, история чтения, «Дочитал!» |
| **Герой** | Эмблема с аурой, уровень и ранг, паутина из 6 характеристик, класс героя (Воин, Мудрец, Друид, Монах, Бард, Творец, Хранитель равновесия), график опыта за неделю, карта активности, достижения |
| **Лавка наград** | Свои реальные награды за золото: кофе, кино, отдых |
| **Достижения** | 26 медалей четырёх ступеней: бронза, серебро, золото, легенда |
| **Настройки** | Профиль героя, ежедневное напоминание (WorkManager), кодекс, сброс прогресса |

### Механика

- **Характеристики:** Сила, Интеллект, Здоровье, Дух, Харизма, Мастерство. У каждой свой уровень.
- **Сложность:** Лёгкий 10 XP · Обычный 20 XP · Сложный 35 XP · Эпический 60 XP.
- **Бонусы:** цель достигнута, перевыполнение, серия (до +100 %), первый шаг дня, возвращение героя,
  идеальный день (все квесты дня, от трёх), книга прочитана (+100 XP).
- **Золото** — 40 % от опыта, тратится в лавке наград.
- **Ранги:** E Новичок → D Искатель → C Странник → B Воитель → A Рыцарь → S Мастер → SS Герой → SSS Легенда.
- **Отмена** последнего выполнения прямо из всплывающей награды: на случай случайного нажатия.

### Анимации

Всё нарисовано на Compose Canvas, без картинок и сторонних библиотек:

- живое северное сияние с мерцающими звёздами; его цвет перетекает при смене вкладок;
- эмблема героя: вращающиеся рунные кольца, дышащее ядро, кольцо опыта, спутники-искры (их больше с каждым рангом);
- кнопка выполнения: заливка с пружиной, прорисовка галочки штрихом, ударная волна и взрыв искр, тактильный отклик;
- тост награды: счётчики XP и золота, бонусы появляются каскадом, полоса характеристики заполняется;
- церемония нового уровня: вращающиеся лучи, ударные волны, 3D-конфетти, число уровня влетает с пружиной,
  при смене ранга торжественно появляется шестигранный знак;
- цифры-«одометры», мерцающие полосы прогресса, пламя серии, парящая 3D-обложка книги,
  раскрывающаяся паутина характеристик, волна тепловой карты, перетекающая подсветка навигации.

## Установка

Готовый APK собирает GitHub Actions (воркфлоу `Ascend Android`):
**Actions → последний запуск → Artifacts → `Ascend-apk`**. Распакуй архив и установи `Ascend.apk`
(Android 8.0+, при установке разреши «из неизвестных источников»).

Сборка вручную (JDK 17 + Android SDK):

```sh
cd ascend
./gradlew :app:assembleRelease   # app/build/outputs/apk/release/app-release.apk
./gradlew :app:installDebug      # сразу на подключённое устройство
```

Или открой папку `ascend` в Android Studio.
Для плавных анимаций лучше ставить release-сборку: отладочные сборки Compose заметно медленнее.

## Архитектура

```
ascend/
├── core/   чистый Kotlin: уровни, ранги, награды, серии, достижения, мотивация (+ тесты)
└── app/    Android: Jetpack Compose, Material 3, Room, WorkManager, Navigation
    ├── data/       Room-сущности и DAO, GameRepository — вся игровая механика в транзакциях
    ├── domain/     модели экранов, планировщик дня
    ├── di/         ручное внедрение зависимостей (AppContainer), шина празднований
    └── ui/         тема, компоненты-анимации, слой празднований, экраны и ViewModel
```

- **Журнал как источник правды.** Опыт, золото и прокачка характеристик считаются из журнала событий.
  Поэтому данные всегда согласованы, а отмена последнего выполнения откатывает его честно.
- **MVVM + однонаправленный поток данных:** Room → Flow → ViewModel (`StateFlow`) → Compose.
- **Тесты:** `./gradlew :core:test :app:testDebugUnitTest` проверяют формулы наград, кривые уровней, серии,
  достижения, а также репозиторий на фейковых DAO: частичный прогресс, равенство путей, отмену,
  книги, идеальный день и лавку.
