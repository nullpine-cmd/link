# Кратные интегралы с нуля

**[kratnye_integraly.pdf](kratnye_integraly.pdf)** — теория кратных интегралов «с нуля» и решения 13 задач
(двойные и тройные интегралы, объёмы тел) по алгоритму из пяти шагов:

1. **Шапка** — слева интеграл, справа граница области с нумерацией поверхностей (1), (2), … и знаками.
2. **Два графика рядом** — область в старых координатах и та же область в новых, где она «распрямляется».
3. **Замена переменных** в столбик и модуль якобиана `|J|`.
4. **Пределы** по второму графику: от констант к зависимостям (углы → радиус/высота).
5. **Повторный интеграл** и счёт изнутри наружу до числа.

Каждый ответ дополнительно проверен независимым способом (другая система координат, геометрия или метод сечений).
Используется только материал стандартного курса матанализа (без бета/гамма-функций).

## Сборка

Исходники — `kratnye_integraly.tex` и папка `tex/` (LaTeX + TikZ/pgfplots).

```sh
pdflatex kratnye_integraly.tex && pdflatex kratnye_integraly.tex
```

Нужны пакеты TeX Live: `latex-extra`, `pictures` (TikZ, pgfplots), `lang-cyrillic`, `cm-super`.
