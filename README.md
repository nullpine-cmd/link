# ARCANA: ASCENT — UI icons

88 interface icons, Major Arcana emblems and suit emblems for the Roblox game
ARCANA: ASCENT, as 256×256 transparent PNGs in `png/`.

They are rendered from SVG by `ui-icons/make_icons.py` in the game's script mirror
and hosted here only so Roblox Studio can upload them by URL
(`https://raw.githubusercontent.com/nullpine-cmd/link/arcana-ui-icons/png/<name>.png`).
